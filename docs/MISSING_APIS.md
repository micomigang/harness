# 爆款复制 Harness：仍需补齐的 API 与凭证

当前真实最小闭环已经具备：Kimi 结构化生成、Seedream 参考图、Seedance 音画视频、本地媒体下载、审批门、失败止损和 FFmpeg 最终拼接。

## 已完成

1. **Kimi LLM**：`kimi-k2.6`，负责分析、剧本、角色/场景/道具、分镜、对白/口型计划、逐镜音效计划、一致性检查和全片配乐方案。
2. **Seedream 图像**：`doubao-seedream-5-0-pro-260628`，生成角色、场景、道具参考图，结果立即落盘。
3. **Seedance 视频**：主模型 `doubao-seedance-2-5-260628`，提交失败时可回退 `doubao-seedance-2-0-260128`；支持参考图、法语对白提示、原生音轨、轮询和结果下载。
4. **FFmpeg/FFprobe**：批量镜头统一编码并拼接为本地 MP4，再检查文件、流、时长、画幅和镜头数。
5. **本地持久化**：SQLite 保存工作区、产物、审批、任务和事件；上传及生成媒体保存在 F 盘项目中。

## 还需要你提供

### P0：要做真实“原视频复制”时必需

1. **源视频语音转写（ASR）凭证**
   - 本地 FFmpeg 探测、1 fps 基础抽帧、scene 切换补帧、音轨提取和页面预览已经完成。
   - 素材分析阶段按默认 30 秒切段，每段最多 12 张代表帧，以时间戳 + Base64 视觉输入并行发送给 Kimi K2.6；成功片段会缓存并支持失败后断点续跑，本地文件路径不会发送。
   - 当前仍没有把 `source-audio.mp3` 自动做 ASR，因此精确对白文本和逐句时间戳仍需要火山语音控制台的 `ASR_API_KEY`，或旧控制台的 `ASR_APP_ID` + `ASR_ACCESS_TOKEN`。
   - 已预填极速版端点和 `volc.bigasr.auc_turbo` 资源 ID。
   - 需要确认允许分析的源视频来源与版权范围。

### P1：纯法语配音增强（可选）

2. **火山语音合成凭证**
   - `TTS_APP_ID`
   - `TTS_ACCESS_TOKEN`
   - `TTS_VOICE_TYPE`
   - 已预填：语言 `fr`、资源 `seed-tts-1.1`、推荐的 V3 单向流式 HTTP 地址。
   - 这套凭证来自火山语音技术控制台，不能使用方舟 ARK API Key 替代。
   - 若 Seedance 直接生成的法语对白与嘴型已满足要求，可以暂时不补。

3. **授权音色素材（只有做声音克隆时需要）**
   - 需要音色权利人的明确同意、可用语种和允许用途。
   - 不提供时使用平台内置法语音色。

### P2：上线与规模化时需要

4. **对象存储**：公开或签名 URL、bucket 与访问凭证；目前媒体均保存本机。
5. **内容安全 API**：提交前审核文本、图片、音频和视频。
6. **成本/配额 API**：余额、预估成本和实扣成本；若供应商无接口，只能本地估算。
7. **Webhook/幂等/取消**：当前 Seedance 使用轮询，尚未实现任务取消、幂等键与 webhook。
8. **独立 BGM API（可选但建议）**：当前会生成完整 BGM cue sheet，但只沿用 Seedance 镜头原生音轨，并明确标记为“未渲染独立 BGM”。需要可控的无对白配乐分轨时，再接入 Seed Audio、Oii Music 或其他音乐 API。

## 不需要提供

- 不需要 OiiOii 登录 Cookie、私有 RPC 或平台积分接口。
- 不需要另一套视频 API；当前视频生成统一走 Seedance。
- 不需要为 Seedream 再购买独立密钥；它与 Seedance 共用同一个火山方舟 ARK Key。

## 当前边界

这是独立本地实现，用于复现工作流功能和交互，不复制目标平台的私有后端。真实人物、受版权保护内容与声音克隆必须由使用者确认授权。
