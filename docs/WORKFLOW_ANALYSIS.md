# 爆款复制 Harness：目标工作流观察与本地映射

## 观察范围

本分析基于 2026-09-19 首次检查与 2026-09-20 复核，对用户提供的已登录工作区进行只读观察。页面内容能证明前端与用户可见工作流；无法据此证明服务端内部实现、私有提示词、计费算法或供应商契约。

## 已观察到的工作区结构

- 工作区以 `tldraw` 无限画布为中心，左/右侧叠加 Agent 对话、任务、资产和编辑器。
- 顶部阶段切换：总览、剧本、角色、场景、道具、分镜、视频。
- 画布上的结构化角色包括：编剧、角色设计师、场景设计师、道具设计师、分镜师、音效总监、艺术总监。
- 角色卡支持角色说明、音色上传、资产库同步、关联分镜数、替换、预览、多视角概念图。
- 场景/道具卡支持描述、资产库同步、关联分镜数、替换和预览。
- 分镜以单镜结构保存，至少包含：场景/时间、视频提示词、音频提示词、对白提示词、时长和生成状态。
- 视频阶段支持单镜预览、批量生成、最终视频预览、下载所有分镜、进入剪辑器。
- 剪辑器提供按镜头裁剪/添加、背景音乐开关、全片播放和导出。
- Agent 对话存在明确的二次确认、撤回到某一步、重新选择、耗时与执行详情。
- 上游修改会提示是否继续级联修改下游分镜图、分镜视频等资源。
- 资产与制作经验是两层概念：技能/方法可复用，工作区媒体资源不能自动跨项目继承。

## 典型阶段

```text
上传素材/制作说明
  -> 素材理解与本地化策略
  -> 剧本
  -> 用户确认剧本
  -> 角色 / 场景 / 道具（可并行）
  -> 分镜拆解与视觉提示词
  -> 独立对白/口型计划 + 独立逐镜环境音/Foley 计划
  -> 连贯性、时代、角色、音频与时长一致性检查
  -> 用户确认分镜
  -> 先生成 1 个分镜预览
  -> 用户确认效果与实际扣费
  -> 批量生成剩余分镜视频
  -> 生成全片 BGM 方案 / 选择音乐渲染策略
  -> 最终拼接
  -> 本地交付质检
  -> 预览 / 剪辑 / 下载 / 发布
```

## 本 harness 的对应实现

| 页面能力 | 本地实现 | 当前边界 |
|---|---|---|
| 项目空间 | SQLite `workspaces` | 可用 |
| 分阶段产物 | 通用 `artifacts` + revision | 可用 |
| Agent 调度 | `Orchestrator` 状态机 + `app/agents.py` 职责合同 | 可用；每阶段唯一主责 |
| 二次确认 | `approvals` gate | 可用 |
| 级联修改 | 依赖图 + stale 标记 | 可用 |
| 任务列表 | `jobs` | 可用；本地后台任务 |
| 历史记录 | `events` | 可用 |
| 画布 | 阶段卡片式 Web UI | 模拟；未复刻自由布局 |
| 剧本/角色/场景/道具/分镜/对白/音效/QA/配乐方案 | Mock 或 Kimi OpenAI-compatible LLM | 结构已就绪；职责已拆分 |
| 图片/视频/音乐生成 | provider 环境位 | 需要 API |
| 视频合成与质检 | `compose` + `delivery_qa` | 本地 FFmpeg 拼接，FFprobe 检查文件/流/时长/画幅 |
| 积分/计费 | 不模拟第三方账户余额 | 可在 provider 返回中记录成本 |
| 发布 Oii TV | 不实现 | 属于 OiiOii 私有平台能力 |

## 前端资源提供的额外信号

页面加载的模块名称包括 `agent_idl`、`backend_workspace_rpc`、`workspace_document_idl`、`data_sync_manager`、`user-assets`、`asset-library-actions`、`create_multi_episode_script_idl`、`resolution_pricing_order`。这支持“结构化文档 + 资产库 + Agent RPC + 数据同步 + 多集脚本 + 模型定价”的判断，但不等于获得了其私有接口定义。

页面模型选择器显示图像、视频和音频为不同 provider 能力层，包含 Oii Image、Seedream、Seedance、MiniMax、Wan、Vidu、Kling、HappyHorse、Seed Audio、Oii Music 等品牌/模型。因此 harness 采用统一适配器，而不是把工作流绑定到某个模型名。

详细职责矩阵、阶段合同、零计费/真实 Provider 调试顺序和故障归属见 [Agent 职责、交接与调试路径](AGENT_ARCHITECTURE_AND_DEBUG.md)。
